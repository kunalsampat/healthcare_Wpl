# Urine Test Strip Reader System

## 📋 Project Overview

The **Urine Test Strip Reader System** is a web-based healthcare portal designed to provide a structured interface for urine test analysis, patient registration, diagnostic reporting, and healthcare information.

The project demonstrates the use of **HTML5 and CSS3** to develop a professional, responsive, and user-friendly healthcare portal. It includes multiple interconnected pages covering patient information, urine test parameters, test procedures, diagnostic reports, and system information.

The system is designed as an educational and healthcare-support interface and demonstrates how digital technologies can be used to organize and present urine analysis information.

---

## 🎯 Objectives

The main objectives of the project are:

* To design a professional healthcare web portal using HTML5 and CSS3.
* To provide information about urine test strip analysis.
* To present important urine test parameters and analytes.
* To provide a patient registration interface.
* To display urine diagnostic results in a structured table.
* To demonstrate HTML formatting and semantic elements.
* To implement navigation between different healthcare portal pages.
* To provide an interactive representation of a urine test strip using an image map.
* To create a clean, modern, and consistent healthcare-oriented user interface.

Contains information about:

### 🔬 Urine Test Strip

Provides an interactive urine test strip interface using an HTML **image map**.

The strip includes areas corresponding to parameters such as:

* Glucose

* Bilirubin
* Nitrite
* Leukocytes
* pH

Provides sections for:
