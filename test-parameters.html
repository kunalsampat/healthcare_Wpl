Urine Test Strip Reader System

Testing Procedure

  1. Collect the urine sample in a sterile container.
  2. Dip the urine test strip into the sample.
  3. Remove excess urine from the strip.
  4. Place the strip inside the strip reader.
  5. Capture reagent pad color changes.
  6. Analyze data using the AI-enabled system.
  7. Generate the diagnostic report.
